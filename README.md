# Task CLI

Une application en ligne de commande (CLI) de gestion de tâches développée en Dart, suivant les principes de l'architecture propre (Clean Architecture).

## Fonctionnalités
- Ajouter, lister, mettre à jour et supprimer des tâches.
- Persistance des données dans un fichier JSON local.
- Gestion robuste des erreurs via des exceptions personnalisées.

## Prérequis
- [Dart SDK](https://dart.dev/get-dart) installé sur votre machine.

## Comment lancer l'application ?
Exécutez la commande suivante depuis la racine du projet :
```bash
dart run
